# Student Finance Tracker

A responsive web app for students to track expenses and manage their budget.

## Features

- Add and delete transactions
- Search and sort transactions
- Regex validation
- Spending statistics
- Budget tracking
- LocalStorage persistence
- JSON import and export
- Currency settings
- Responsive design

## Technologies

- HTML
- CSS
- JavaScript
- LocalStorage
- JSON

## How to Run

Open `index.html` in a browser or use VS Code Live Server.
